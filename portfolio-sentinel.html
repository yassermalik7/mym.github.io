Project information

  • Name: Sentinel – Agentic QA Automation Platform
  • Date: 2026
  • Company: Self-directed build (Cursor + Claude)
  • Tech stack: TypeScript (strict), Node 20, pnpm workspaces, Playwright, MCP SDK, Anthropic Claude, Vitest, Next.js, GitHub Actions

What is it?

An end-to-end agentic UI test platform: it takes a plain-English goal and a URL, plans a multi-step test, executes it via Playwright, self-heals broken locators, classifies failures and produces a self-contained HTML report.

Architecture and acceptance criteria were directed personally; implementation was generated by Cursor under direction and reviewed against spec.

Key features

  • Agentic test execution: a plan→act→observe→reflect loop converts plain-English goals into structured Playwright steps, with deterministic replay from saved runs for regression-style re-runs without re-planning.
  • Self-healing locator strategy: a two-stage healer scores DOM candidates deterministically (role, accessible name, nearest text, attribute similarity), escalating to an LLM-assisted choice only on low confidence. Reasoning is persisted to the report for auditability.
  • Failure classification: a rule-first classifier distinguishes locator drift, assertion failures, suspected app bugs, infrastructure errors and flakes using deterministic signals before falling back to LLM judgement, keeping test signal reliable.
  • MCP-based architecture: all browser actions are exposed through a Model Context Protocol server, enforcing a clean boundary between agent intelligence and browser tooling – making the system tool-swappable.
  • Demoable validation harness: a companion TestBed web app with toggleable chaos modes (locator drift, flake injection, broken endpoints) validates every healing and classification path end-to-end, with a GitHub Actions workflow demonstrating the agent in CI.
  • Engineering discipline: per-run token-budget guardrails, structured JSON logs, unit tests around the healer and classifier with mocked LLM fixtures, and ADRs documenting key trade-offs.
